# JETS (Just Enough Tavern Search)

酒馆全局搜索插件：角色卡 / 世界书 / 聊天历史 / 预设 / 设置 / 按钮一键直达。

## 能解决什么问题
- 设置太多找不到？直接搜按钮名或功能名。
- 角色、世界书、聊天记录太多？一处搜索全局定位。
- 想找"某个人物相关的某段对话"？常驻关键词叠加筛选。
- 移动端操作麻烦？输入框左下角的 ☰ 菜单里有全局搜索入口，弹窗可随时关闭。

## 主要功能
- **面板主题**：默认深色 / 疏星（流动星云 · 微闪星光 · 石英质感），齿轮设置里一键切换，文字区铺玻璃底不吃可读性
- **全局搜索**：角色卡 / 世界书 / 聊天历史（含全部消息）/ 预设 / 设置 / 功能按钮
- **预设全覆盖 + 使用中锁定**：对话补全 / 文本补全 / KoboldAI / NovelAI / 上下文 / 指令 / 系统提示 / 推理模板全部入索引；正在使用的预设带「使用中」徽标并自动置顶，一眼锁定
- **分类筛选**：全部 / 角色聊天 / 世界书 / 预设，「全部」是总控：全亮时点它一键全灭、未全亮时点它一键全开，具体分类独立多选（自动记忆）
- **常驻关键词**（叠加筛选）：添加人名等关键词（如"澄"），启用后结果必须同时包含关键词——搜"可爱"+启用"澄"，只出两人同框的记录；关键词可叠加，越多越精准，青色高亮区分
- **思维链过滤**：不把 `<think>`、`<thinking>` 等推理内容算进搜索（可开关，可自定义标签）
- **秒级加载**：索引结果存本地缓存（IndexedDB），二次打开酒馆即时可搜；后台只在空闲时增量索引，AI 生成回复期间自动暂停，不拖累酒馆性能
- 支持中文本地化文本检索、回车直接执行（自动展开折叠项）
- Alt+K 快捷键 + 输入框左下角 ☰ 菜单内的「全局搜索」入口（PC / 移动端）
- 移动端友好：搜索弹窗有关闭按钮，可点空白处关闭

## 安装
1. 打开 SillyTavern → 顶部【扩展】图标
2. 点击【安装扩展】
3. 粘贴仓库地址：`https://github.com/<你的用户名>/st-jets`

### 离线安装（给没有梯子 / 内网的朋友）
1. 拿到 `st-jets` 文件夹（zip 包解压出来即可）
2. 整个文件夹复制到 SillyTavern 的 `public/scripts/extensions/third-party/` 目录下，最终路径必须是 `.../third-party/st-jets/manifest.json`（没有 `third-party` 文件夹就手动新建一个）
3. 重启 SillyTavern（或浏览器 Ctrl+F5 强制刷新），在扩展列表启用「全局搜索」即可

效果与在线安装完全一致——在线安装本质上只是把仓库下载到同一个位置。

想发布自己的版本？看 **小白级发布教程：`docs/deploy.zh-CN.md`**（注册 GitHub → 上传 → 生成安装链接，约 10 分钟）。

推荐：安装 ST API Wrapper，可提升聊天跳转/滚动稳定性与索引体验。

## 使用
- 打开：`Alt + K`，或点输入框左下角的 **☰ 菜单 → 全局搜索**（PC / 移动端）
- 输入关键词，回车执行；上下键选择结果，ESC / 关闭按钮 / 点空白处关闭
- 搜索框下方 **分类 chips**（带图标和专属色）：点「全部」一键全开/全灭（三个分类全亮时它自动亮），具体分类各自点亮/熄灭，可叠加
- **常驻关键词**：点词条行的 **+** 添加人名等关键词，回车可连续添加；点击词条启用（亮）/停用（暗），× 删除
- **齿轮设置 → 面板外观**：默认 / 疏星两种主题一键切换（立即生效并记忆）
- **齿轮设置 → 内容屏蔽**：开关「屏蔽思维链 / XML 标签」，下方直接填写要屏蔽的标签名（如 `dream`）；另有索引状态与重建
